验证日期：2026-11-12（Asia/Shanghai）。平台为 Ubuntu 24.04、ROS2 Jazzy、C++17、系统 Python 3.12。功能代码基线为 `64bb347`；本文只记录实际执行结果。

三配置使用各自 build/install 目录，均完成 `colcon build`、`colcon test` 和 `colcon test-result --verbose`。全部原有 18 个 Google Test 目标已迁移；没有忽略原有包。默认/全功能配置中 3 个传统模式 fixture 的跳过已在传统配置执行通过。唯一未执行自动用例是依赖外部 `rpg_datasets/rpg_vfr_pinhole` 的 `TestDepthEstimation.DISABLED_testDataset`。

全部 25 包的 ament 安装索引有效。三配置实际链接均为系统 OpenCV 4.6，未混用用户 OpenCV 4.13，也没有缺失动态库。本机 OpenGV 采用 Noble 官方二进制包的隔离前缀；常规系统安装步骤见 [运行指南](ROS2_JAZZY.md)。
