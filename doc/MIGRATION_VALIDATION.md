同一 `job_002.mcap`、原 `calib.yaml` 和含其他 VIO 先验的 `trajectory_gt_imu.txt`，从零偏移开始。八组快速筛选后，四组最终配置各进行三次 1 倍速离线运行；均为 4909 组图像、65856 条 IMU、2 个前导跳过、4907 次估计及有效位姿，丢失/重置/溢出/重复/回跳均为零，队列排空。精度主口径为尺度固定 1、全重叠段 SE(3) 对齐，4620 个匹配位姿；同时保存 Sim(3) 及固定 1 秒 RPE。

组合参数为窗口 8、观测标准差 3、特征/地图特征上限 450/750。其 ATE 中位数较低，但与默认的复跑范围重叠，尚不能认定稳定提升，未更改默认参数。三次回环均为检测/应用校正/完成 PGO 次数零，本序列未验证到回环收益；仅开启回环开关也会改变额外地图点配置，不能把数值差异归因于回环。

证据位于项目 `output/vio_compare_20261112_matrix/`，含逐次参数、构建缓存、命令、日志、MCAP、轨迹、SE3/Sim3 和同时间戳 PGO 评估、`results.json`、`report.md` 与 `comparison.png`。复现入口为 `scripts/compare_ego_vio.py`，说明见 `doc/EGO_VIO_COMPARISON.md`。快速筛选期间有构建/预检负载，最终复跑在 C++ 构建结束后串行进行；回环初期曾修复 Python 辅助评估包，首轮缺失的 1 秒 RPE 已从保存轨迹补算，估计未重跑。这些结果不构成独立绝对精度或严格隔离 CPU 性能基准。
